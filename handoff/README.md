# handoff 分支：Claude ⇄ 执行方交接区

本分支只放交接文件，**永不合并进 master**，正式版保持干净。用户不搬运文件。

## 分工

| 角色 | 做什么 | 写哪里 |
|---|---|---|
| Claude（指挥） | 讨论、定方向、写任务单、审核执行汇报 | `handoff/` 下的任务单、交接文档 |
| 执行方（Codex / Antigravity 等） | 读代码、写代码、跑测试、构建 | 代码在自己的功能分支；汇报写 `handoff/reports/` |
| 用户 | 拍板、本机实测 | 不需要动文件 |

## 文件约定

- `MDCx任务单_vX.Y.md`：给执行方的任务，只由 Claude 写。新任务出新版本号，不覆盖旧版。
- `MDCx交接文档_vX.Y.md`：项目现状，只由 Claude 写；版本号最大的是现行版本。
- `reports/MDCx_执行汇报_vX.Y.md`：执行方对同编号任务单的汇报，只由执行方写（v1.3 及以前叫 `MDCx_Codex汇报_vX.Y.md`）。返工时出 `_vX.Y-r2` 这样的后缀，不覆盖。
- 同一轮的任务单、汇报、交接文档共用一个版本号。

## 流程

1. Claude 把任务单推到本分支，给用户一句 执行方启动提示词。
2. 用户把提示词粘给执行方（新开对话）。
3. 执行方干完，把汇报推到 `reports/`。
4. 用户告诉 Claude「汇报好了」，Claude 自己读、审核，给出结论或下一版任务单。
