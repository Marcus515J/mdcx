MDCx 本机 Hy-MT2 可选外部启动包

第三阶段 MDCx 已可在 设置 → 翻译 → LLM 翻译 底部直接查找、启动、停止模型并保存路径。
日常使用优先选择软件内启动，无需本 ZIP。模型手动启动后作为备用，DeepSeek 云端为主接口。

若需要使用本外部启动包：
1. 将 ZIP 整个解压到一个文件夹。不要在压缩包里直接运行。
2. 双击 Start-HyMT2.cmd（不要双击 PS1）。不需要管理员权限。
3. 输入大概安装在哪个盘，例如 H；不确定可输入 D E H。
4. 查找现有安装记录、程序与模型。多份安装可选择；等待显示“服务已就绪”。
5. 打开 MDCx：设置 → 翻译 → 将本机 Hy-MT2 设为备用。
   备用地址：http://127.0.0.1:8080/v1；备用模型：HY-MT2-7B-Q8_0；备用 Key 留空。
   若启动窗口提示实际模型名不同，再修改备用模型名，最后点底部“保存”。
   原云端地址、模型、Key、私有 Prompt 和温度保持原样。
6. 保持外部窗口打开；结束后按回车停止本次启动的模型。
   外部启动的服务由本窗口管理，MDCx 只复用，不会停止它。

错误窗口会保留，并显示日志位置。通常是解压文件夹里的 logs；只读时回落到 LocalAppData。
本外部启动包每次重新查找；软件内功能则记忆保存的路径。
端口占用不强行关闭其他程序；复用现有安装，不下载模型、不安装依赖，不读取私人 API Key/Cookie。
