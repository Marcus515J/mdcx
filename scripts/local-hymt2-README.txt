MDCx 本机 Hy-MT2 启动包

1. 将 ZIP 整个解压到一个文件夹。不要在压缩包里直接运行。
2. 双击 Start-HyMT2.cmd（不要双击 PS1）。不需要管理员权限。
3. 输入你大概安装海南鸡/模型的盘符，例如 H，然后回车。
   不确定可以输入多个盘符，例如 D E H。无需找程序或模型文件。
4. 启动器会优先查找海南鸡的安装记录；找不到记录再查找程序和模型。
   大盘可能需要几分钟，扫描和加载过程会显示进度。
5. 等窗口显示“服务已就绪”，再打开 MDCx：
   设置 → 翻译 → 本机 Hy-MT2 预设 → 保存，然后开始刮削。
   主地址：http://127.0.0.1:8080/v1；模型：HY-MT2-7B-Q8_0；主 Key 留空。
   如果窗口提示复用服务的模型名不同，先点击本机预设，
   再按窗口提示改主模型名，最后保存。预设会覆盖模型名，所以顺序不能颠倒。
6. 使用期间保持启动窗口打开。使用结束后按回车停止本次启动的模型。

出错也不会一闪而过。窗口会保留错误，并显示日志文件夹位置。
通常是解压文件夹里的 logs；若该文件夹只读，放在本机 LocalAppData 下。
没有找到安装时，可重新运行并选择另一个盘。
多份程序/模型可能需要选序号；当前版本每次启动会重新查找，不保存安装位置。
端口已占用时不会强行关闭其他程序；若海南鸡正加载模型，等它加载完再运行。
本启动包复用已安装文件，不下载模型、不安装依赖，不读取私人 API Key/Cookie。
