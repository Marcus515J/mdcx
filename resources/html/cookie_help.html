MDCx Cookie 获取与配置教程

适用于 Chrome / Edge 浏览器获取站点登录 Cookie 并填入 MDCx

一、如何在 Chrome / Edge 开发者工具中复制 Cookie

  1. 使用 Chrome 或 Edge 浏览器打开目标站点（若在 MDCx 中配置了该站点的自定义镜像网址，请打开同一个域名），完成登录或年龄确认。
  2. 在页面空白处点击鼠标右键选择 检查（Inspect）（或直接按快捷键 F12 / macOS 按 ⌥ Option + ⌘ Command + I）打开开发者工具。
    示意图，菜单名以你的浏览器实际界面为准
  3. 在开发者工具顶部切换到 Network（网络） 面板，筛选栏选择 All（全部） 或 Doc（文档），然后按 F5 刷新当前网页。
    示意图，菜单名以你的浏览器实际界面为准
  4. 在请求列表顶部点击第一条主页面请求（通常与当前网页路径同名），在右侧详情区切换到 Headers（标头） → 展开 Request Headers（请求标头），找到 Cookie（或 cookie）字段。
    示意图，菜单名以你的浏览器实际界面为准
  5. 优先在 Cookie（或 cookie）这一行上点击鼠标右键，选择 复制值 / Copy value；如果右键菜单中没有该项，再手动框选该行对应的值文本并右键复制（或按 Ctrl/⌘ + C）。注意菜单名以你的浏览器实际界面为准。
    示意图，菜单名以你的浏览器实际界面为准
提示：优先使用右键菜单中的“复制值 / Copy value”可避免长 Cookie 在手动框选时光标截断或漏选字符。不同浏览器或语言版本的右键菜单名称可能略有差异，请以你的浏览器实际界面为准。

二、粘贴到 MDCx 的哪个设置项

打开 MDCx 主界面，依次进入左侧导航栏「设置」页中的「网络」标签页，在「Cookie设置」分组中，根据站点将复制好的 Cookie 粘贴到对应输入框中：

示意图，菜单名以你的浏览器实际界面为准
站点设置项 用途说明 验证方式
javdb 访问 JavDB 登录态受限页面（如 VIP/登录可见条目）或降低风控拦截频率 粘贴后点击右侧 「检查cookie」 按钮验证有效性
javbus 访问 JavBus 需登录或年龄验证的页面 粘贴后点击右侧 「检查cookie」 按钮验证有效性
fc2ppvdb 访问 FC2PPVDB 时携带浏览器会话 / 验证 Cookie 粘贴后点击右侧 「检查cookie」 按钮验证有效性
保存与有效期提醒：
  • 点击「检查cookie」仅用于测试当前输入框内的 Cookie 是否有效；测试通过后请点击界面右下角的 「保存」 使其正式生效。
  • Cookie 具有有效期，当日志提示 Cookie 失效或再次触发登录跳转时，请按上述步骤重新获取并更新。
