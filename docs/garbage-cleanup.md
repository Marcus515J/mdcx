# 无番号垃圾文件处理

在「设置 → 刮削目录」中点击「垃圾处理设置…」，可直接编辑总开关、演练模式、黑名单（每行一项）、域名规则、N、单文件处理方式和待删位置，点击「保存并生效」。
也可退出程序后编辑当前使用的 JSON 配置（路径由 `MDCx.config` 指定），重新启动生效。
现有设置页的最小文件大小也用于这里的 N，不重复新增大小设置。

| JSON 键 | 默认值 | 说明 |
|---|---|---|
| `garbage_enabled` | `false` | 自动处理总开关；需启用 |
| `garbage_keywords` | `["台湾uu", "美少女直播", "信誉保证", "最新情報", "最新情报"]` | 去除所有空白后包含匹配 |
| `garbage_domain_rule` | `true` | 去空白后检查 `.com`、`.net`、`.cc`、`www.` |
| `file_size`（已有） | `100.0` | N，MB（1024² 字节），严格小于；仍保留原有小文件过滤用途 |
| `garbage_permanent_delete` | `false` | 关闭时移动，开启时永久删除 |
| `garbage_directory` | `""` | 空为源文件盘符/卷根下 `_待删`；可设绝对路径 |
| `garbage_dry_run` | `false` | 演练：记录日志、跳过搜索、零文件改动 |

只有视频扩展名且现有提取器无法提取番号，并且命中关键词、域名或大小条件的文件才会处理。
混合目录中只处理垃圾视频，不处理 NFO、软链接或正常番号视频；重名加 `_1`、`_2` 等序号，既有目标文件不会被覆盖。
`_待删` 及自定义待删位置（包括子目录）从扫描和显式任务中排除。
总开关关闭保持原有扫描处理行为，但待删目录仍始终排除。
处理失败记录日志并跳过站点搜索，原文件保留。


## 刮削结束后的目录处理

整轮刮削完成后，若媒体根目录下的某个子目录及其子目录只包含已确认的垃圾文件，就把整个目录移到 `_待删`，保持内部结构。媒体根目录、排除目录、软链接目录不会被移动。
垃圾视频沿用同一番号/黑名单/大小判断；非视频文件仅复用现有启用的 `clean_ext`、`clean_name`、`clean_contains` 正向规则及排除项，不因文件小就判为垃圾。默认例如 `.url`、`.html` 广告文件可命中。
目录里只要还有正常番号视频、NFO、图片、字幕、未知文件或链接，就不会整体搬走。空目录不按垃圾目录处理。
纯垃圾目录在扫描时跳过站点搜索并延后处理，整轮结束后统一移动；演练只记录计划。即使单文件设置为永久删除，整目录仍按本次补充要求移到待删，不永久删除目录。
目录移动先复制到独占创建的目标（同名加序号），核对源文件未变化后只移除已复制的垃圾文件及空目录。权限/复制失败或目录内容变化时记录失败并保留源文件；可能留下待删副本，不会强制删除源目录的新文件。


每轮开始会明确记录总开关及演练/真实处理状态。看到 `演练` 表示识别成功但不会搬文件，切换为真实处理无需先成功刮削正常视频。
非视频垃圾规则仍在当前页原有清理设置中编辑（扩展名、完整文件名、包含关键词及排除项），不要为了目录移动开启旧版永久自动清理。
