# 本机模型管理

Windows 入口：「设置 → 翻译 → LLM 翻译」底部的「本机模型管理」。它使用已安装的 llama-server.exe 和 GGUF，不下载或安装模型。

## 首次使用

1. 在「查找盘符 / 目录」填写大概所在盘符（例如 H），或点击「选择位置」选择安装目录。
2. 点击「查找 / 验证路径」，从列表选择服务程序和模型；找不到时可点击「浏览」补充。
3. 点击「启动备用模型」，等待状态显示就绪。
4. 点击页面底部「保存」，记住路径及备用配置，再开始刮削。

有效 GGUF 都会列出，包括 Hy-MT2 和 Index-Translate；默认优先 Hy-MT2。实际是否能加载取决于已安装 llama.cpp 的模型支持和本机资源。
启动模型的接口 ID 使用文件名去掉 .gguf，例如 HY-MT2-7B-Q8_0 或 Index-Translate-9B.Q6_K；复用外部服务时读取它的实际 ID。

## 查找与切换

Windows 界面路径统一显示反斜杠，两种分隔符输入均可接受。
记忆路径有效时，「查找 / 验证路径」只验证选中路径并保留已知候选；新增模型请点「重新查找」扫描完整列表。
多个盘符可用空格分隔（如 H D）；目录里的中文、空格和方括号保留原样。

切换模型前先停止已有服务，再选择模型并启动。不能把正在运行的不同模型静默当成新选择的模型使用。
软件只停止自己启动的进程，外部服务需要在原启动程序中停止。刮削期间停止按钮禁用。

## 状态与日志

查找、加载和停止在后台进行；例行健康检查不禁用控件。加载期间显示等待时间，允许取消。
文件缺失、端口占用、加载超时和异常退出会显示原因。「打开日志」打开配置目录 logs/hymt2 中本次日志；无写入权限时使用本机应用数据目录。
日志包含 manager.log、server-stdout.log 和 server-stderr.log；stdout 为空可能是正常现象。

退出 MDCx 时关闭本软件启动的模型。取消退出、托盘隐藏和最小化不会停服。
软件内进程管理适用于 Windows；Mac 可继续使用原有功能和兼容备用接口，不提供 Windows .exe 模型启动。

主云端配置、私有 Prompt 以及独立的主/备用温度均保留，详见[云端翻译与本机备用](llm-refusal.md)。
