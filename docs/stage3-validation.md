# 第三阶段：软件内模型管理与控件统一

从 `feat/local-hy-mt2-translation` 最新交接提交 `bd7c42c` 建立 `feat/local-hymt2-ui`。
本阶段实现模型使用界面，延续已验收清理和翻译故障回退。主分支、PR #4、历史测试版保留。

## 实现

- 原设计仍是 PyQt6 固定主窗、滚动设置页、controller 动态扩展、页面底部总保存。`.ui` 和生成文件没有分叉修改。
- 清理和翻译页改为分组纵向布局；新增行使用同一标签列、最小控件高度、间距。主题样式读取原深浅主题 tokens，去掉复制局部样式；清理/模型下拉在创建后统一初始化。
- 模型区域支持盘符/目录后台查找、安装记录、全部候选选择、浏览、记忆路径验证、强制重新查找。跳过系统/隔离目录、链接及 Windows reparse points；只读取非私人安装记录。
- 现有 llama-server/GGUF 使用头部验证，不安装、不下载。启动沿用已验证的 GPU/context、回环地址与模型 alias 参数，按参数列表传递路径，不经过 shell。
- 后台加载、健康与实际模型 ID 检查；端口占用、文件缺失、加载超时、异常退出显示原因。进度显示等待秒数和忙碌指示，不伪装模型加载百分比。
- 所有权按 Popen 子进程句柄管理；外部服务只复用。停止在工作线程执行，重复点击不重复启动；扫描/加载可取消；刮削期间禁止停止，正常退出前清理自己的服务。取消退出、最小化、托盘隐藏不清理。
- 启动/预设只填写备用 URL/Model/Key，保留云端地址/模型/Key、Prompt、温度、重试和其他选择。后台结果遇到配置切换不覆盖新配置的路径或备用字段。
- 路径与备用设置随原总保存持久化。加载不写 JSON；本轮未索取/读取用户私人 JSON 或历史 NFO。新建配置默认 DeepSeek 标准地址、通用 `deepseek-chat` ID、主请求尝试 1、温度 0.90；不迁移/猜测已有云端模型。
- 软件内手动启动为本阶段策略，没有自动加载或云端失败时启动模型。外部启动器保留为可选入口，提示已改为本机备用。
