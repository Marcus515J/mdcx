## 日常使用恢复

故障测试后恢复正确的 DeepSeek 主模型名并保存；需要本机备用时，
用现有 `Start-HyMT2.cmd` 启动并保持服务窗口打开。
主接口保持自己的云端地址/模型/Key，备用地址 `http://127.0.0.1:8080/v1`，
备用模型 `HY-MT2-7B-Q8_0`，备用 Key 留空。
翻译服务只勾选 LLM，云端主模型尝试 1，拒绝/不可用重试 1。
旧启动器提示点击本机主接口预设属于此前用法；当前云端优先配置不要点击该预设。
