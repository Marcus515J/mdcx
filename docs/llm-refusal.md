# 云端翻译与本机备用

入口：「设置 → 翻译 → 翻译引擎 / LLM 翻译」。软件当前仅保留大模型（LLM）作为在线/本地翻译引擎；日常使用任意兼容 OpenAI 接口的云端主模型，遇到安全拒绝、请求错误、超时或空返回时按设置重试，再回退请求本机备用模型；仍失败则保留对应字段原文。

标题和简介分别处理，互不覆盖另一字段已成功的译文。日志显示重试、备用和原文步骤，汇总区分完整翻译、部分翻译及未获得译文。简介保留原文时沿用原来源。

## 设置

| 控件 | 日常设置 |
| --- | --- |
| 主 API URL / Model / Key | 填写可用的 OpenAI 兼容云端配置（Key 明文显示） |
| 云端主模型尝试 | 1，控制主接口请求错误的内部尝试 |
| 拒绝 / 不可用重试 | 1，控制主接口失败后的重试 |
| 主/备用读取超时 | 默认 60 秒，可按实际响应时间调整 |
| 主接口温度 | 默认 `0.2`，独立控制云端主接口采样温度 |
| 备用接口温度 | 默认 `1.0`，独立控制备用接口采样温度 |
| 标题/简介 Prompt | 沿用自己的设置；主接口与备用接口共用同一套标题/简介 Prompt |
| 本机备用 URL | `http://127.0.0.1:8080/v1` |
| 本机备用 Model | 本机模型启动成功后自动回填实际模型 ID |
| 本机备用 Key | 本机地址可留空（非本机备用地址按需填写，明文显示） |

旧版配置若包含已移除的谷歌、百度、DeepL、DeepLX 引擎或相关密钥字段，加载时会自动清理并收敛为仅使用 LLM，保存后不再写出旧字段。
所有设置使用页面底部「保存」。本机模型操作只更新备用接口，不覆盖云端地址、模型、Key、私有 Prompt 或主备温度。
关闭「使用备用模型」或备用地址留空可停用备用；没有可用备用时保留对应字段原文。

## 本机服务

Windows 可直接在软件内查找、启动和停止已有 GGUF 模型，见[本机模型管理](local-models.md)。无需外部启动包。
本机请求隔离应用和环境代理，不跟随重定向；云端沿用原代理配置。主接口与备用接口共用标题/简介 Prompt，但分别发送各自独立的温度参数；本机及备用每一步只请求一次。
本机仍需在软件内手动启动；云端失败时不会自动加载模型。

## 边界

开头拒绝语、请求错误、超时和空返回会触发回退。句中普通拒绝词不会被当成整段拒绝。
语义错误（例如主宾颠倒、姓名差异）不会自动触发备用；程序不进行自动语义评审、不批量改写已有 NFO。
使用日志排查时无需提供私人 Key、Prompt、Cookie 或完整配置。
