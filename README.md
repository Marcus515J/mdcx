## 功能与版本说明

正式功能说明：[文件清理](docs/garbage-cleanup.md)、[云端翻译与本机备用](docs/llm-refusal.md)、[本机模型管理](docs/local-models.md)。

* **翻译引擎**：使用大模型 API（支持兼容云端主接口与本机备用模型、独立主备温度），旧版翻译引擎已移除（旧配置自动平滑迁移）。
* **扩展资源**：演员头像包、字幕包、水印包及演员资料库等第三方资源统一托管于私有资源仓库，需使用有访问权限的账号登录下载。

> 一般情况无需自行构建，请到[本仓库 Releases](https://github.com/Marcus515J/mdcx/releases) 下载发布版本。
> 当前提供 Apple 芯片 Mac（macOS aarch64）和 Windows x86_64 安装包；上游仓库的版本与本仓库独立发布。

正式版沿用本仓库的 `v主版本.次版本.修订号`，当前为 **v1.3.9**，延续 `v1.0.1 → v1.0.2 → v1.1.0 → v1.1.1 → v1.2.0 → v1.3.0 → v1.3.1 → v1.3.2 → v1.3.3 → v1.3.4 → v1.3.5 → v1.3.6 → v1.3.7 → v1.3.8`。
软件显示、更新比较、发布标签和成品名称统一使用这套编号；系统文件属性使用对应的数字版本 `1.3.9`。
曾发布的 `220261012` 日期编号版已被替代，下载最新版并沿用原配置即可；旧版更新检查不能解析新标签，需要手动替换一次。

本版汇集 v1.3.8 之后的 DMM 抓取修复；翻译使用大模型 API。日常推荐配置 2.15；配置文件由使用者单独保留，不入库、不随发布包分发。完整变更见 [发布说明](changelog.md)。

### 评价后缀保留

入口在「设置」→「命名」→「马赛克命名规则」→「评价后缀词表」。词表里的词之间用空格分隔，大小写敏感、按完整词匹配；留空即关闭，关闭时沿用原有命名行为。

开启后，原文件名末尾「-」后面全是词表里的词时，这部分后缀会保留到整理后文件名的末尾，位置在分段号之前；随行文件和同名字幕一起沿用新名称。已经带后缀的成品再次刮削不会重复追加。NFO 的标题和标签不含这个后缀。

只有最后一级文件夹模板包含标题或原标题字段时，文件夹名才在末尾接上后缀；按演员、番号等字段建立的文件夹，以及只有上级目录含标题的情况，都不接后缀。

原文件名末段混有词表外的词、同时又有词表内的词时，该片不做清理、不发站点请求，留原地。日志和请求信息总计会单列“留原地（评价后缀待检查）N”；整批只有留原地、没有成功任务时，显示为批次结束，不显示成功提示。

### 演员署名确认

有码片、无码片的来源给出“名A（名B）”这类组合演员名时，程序按本作翻译前的标题、简介确认署名：只有其中一个名字在标题或简介里唯一出现时，才用它作为作品署名，并同步到两个演员字段；对不上就保留原样，也不会被去括号规则截断，日志提示“演员署名未确认”。

已确认的署名做语言映射时，只按完全相同的主名查对照表；只命中别名时保留作品署名，不会被对照表换成另一个主名。

素人片、FC2 不走这一步，保持原有流程。

### 开发与构建环境

当前主分支要求 Python 3.13.4 或更新版本，依赖和验证方法见 [开发说明](CONTRIBUTING.md)。自动发布使用 Python 3.13，构建目标为 macOS aarch64 和 Windows x86_64。

旧 `Build and Release v1` 工作流已移除，历史仍可在 Git 中查阅。当前构建与版本发布流程见 [开发说明](CONTRIBUTING.md)，安装包以本仓库 Releases 实际提供的文件为准。
